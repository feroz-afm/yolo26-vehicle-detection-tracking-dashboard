# YOLO26 Vehicle Analytics Dashboard

This project implements a YOLO26-based computer vision system for vehicle detection, tracking, and real-time traffic analytics from road video footage.

The system detects and tracks multiple vehicle classes including cars, motorcycles, buses, and trucks. It also generates a dashboard-style output showing live object counts, class-wise vehicle distribution, tracking summary, and object size categories.

## Features

- Vehicle detection using YOLO26
- Object tracking with ByteTrack
- Real-time vehicle count overlay
- Class-wise counting for car, motorcycle, bus, and truck
- Analytics dashboard visualization
- Output video generation with detection and charts

## Classes

- Car
- Motorcycle
- Bus
- Truck

## Tech Stack

- Python
- YOLO26 / Ultralytics
- OpenCV
- ByteTrack
- Kaggle Notebook

## Output

The final output combines the detected traffic video with a real-time analytics dashboard for vehicle monitoring and visualization.
